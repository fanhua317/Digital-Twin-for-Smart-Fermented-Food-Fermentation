# 功能清单

## 🏭 工艺仿真（ProcessSimulationService）

### 核心仿真循环
- [x] 1 秒/拍调度，物料严格守恒（输入 = 输出 + 存量变化）
- [x] 5 核心设备持续加工（搅拌机 → 上甑机 → 蒸馏塔 → 摊凉机 + 输送泵）
- [x] 8 AGV 独立状态机，各自专属任务角色（起糟 / 配料 / 上甑 / 出甑 / 入池）
- [x] 100 窖池发酵状态机：empty → filling → fermenting → ready → discharging
- [x] 发酵时间加速（1 实秒 ≈ 2 仿真小时，60 天 ≈ 12 实分钟）

### 物料流
- [x] 原料仓（粉粮 / 稻壳 / 曲粉）低于 30% 自动补充至 95%
- [x] 搅拌机自动从粉粮仓 / 稻壳仓拉料（33% + 8%）
- [x] 摊凉机自动从曲粉仓加曲（5%）
- [x] 输送泵持续向蒸馏塔供底锅水（10 kg/s），防饥死
- [x] AGV 装卸货时精确扣减 / 累加设备物料层级（无幽灵物料）
- [x] AGV 找不到入池目标时 backpressure 等待，货物不丢失

### 馏酒与储罐
- [x] 蒸馏塔自动分级接酒：头酒 5% / 中段 85% / 尾酒 10%
- [x] 三联储罐（头酒 5000 kg / 中段 15000 kg / 尾酒 5000 kg）
- [x] 储罐达 90% 自动放空至 30%（模拟出厂灌装 / 转储）

### 批次管理
- [x] 每批次目标 500 kg，完成后自动开启新批次
- [x] 重启后孤儿批次（in_progress）自动收尾，确保唯一活跃批次
- [x] `actualVolume` 随中段酒累积实时更新，前端进度条实时跟踪

### 告警生成
- [x] 窖池温度 / 湿度 / pH 超阈值随机告警
- [x] 设备故障概率告警（CRITICAL / WARNING / INFO 三级）

## 🎮 3D 数字孪生（Three.js + React Three Fiber）

### 场景元素
- [x] 100 个窖池模型，颜色编码阶段（灰=空 / 黄=入池 / 绿=发酵 / 橙=待起糟 / 红=起糟）
- [x] 糟醅类型颜色编码（红糟 / 楂醅 / 丢糟）
- [x] 5 核心设备 3D 模型（搅拌机 / 上甑机 / 蒸馏塔 / 摊凉机 / 输送泵）
- [x] 8 AGV 移动动画，时间基线性插值（1200ms 窗口）
- [x] AGV 气泡标签：任务阶段 / 货物类型 / 重量 / 温度 / pH / 来源窖池
- [x] 蒸馏塔高塔模型 + 摘酒管道动画
- [x] 头/中/尾三联储罐 + 液位高度动画
- [x] PUMP → 蒸馏塔水管道模型
- [x] 环境光 / 方向光 / 点光源组合照明
- [x] OrbitControls 自由旋转 / 缩放 / 平移

### AGV 平滑动画优化
- [x] 位置插值窗口 1200ms（防网络抖动导致的跳帧）
- [x] 位置差异阈值 0.5m（微小变化不触发动画，避免抖动）
- [x] React.memo 包裹各 AGV，精准更新防重渲

### HUD 条（SceneHUDStrip，画布外）
- [x] 全厂实时统计（窖池总数 / 设备运行数 / 告警数 / 累计产量）
- [x] 摊凉机三段温度实时显示（85°C → 60°C → 35°C）
- [x] 原料仓三色进度条（粉粮 / 稻壳 / 曲粉）
- [x] 三联储罐液位进度条（头酒 / 中段 / 尾酒）

### 工艺导览（SimulationController）
- [x] 7 步工艺引导卡（起糟 → 配料 → 上甑 → 蒸馏 → 出甑 → 摊凉加曲 → 入池发酵）
- [x] 每步自动定位摄像机到对应区域
- [x] 暂停 / 继续 / 重置仿真控制条
- [x] 实时数据面板（SimulationPanel）并排显示

### 性能分析
- [x] OEE 综合设备效率实时计算
- [x] 设备可用率 / 性能效率 / 产品合格率
- [x] 24h 能耗趋势折线图
- [x] 出酒率趋势图
